## 建模与控制

- 建立沿水平导轨运动的 **1 kg 小车**，铰接一根 **0.2 kg、长 0.6 m 的均匀自由摆杆**。以直立为零角，记录坐标、单位、重心、惯量和阻尼，推导直立附近的四状态模型，绘制控制框图。先关闭反馈，核对正向推力使小车向正方向运动、微小偏角会自然增大。
- 实现两种 C++17 控制器。**串级 PID** 由位置外环给出目标倾角，姿态内环给出小车推力，记录调参过程与抗积分饱和措施。**离散 LQR** 同时反馈位置、速度、摆角和角速度，用 Python 脚本从模型和权重重新计算增益。两者共用传感器状态估计、2 ms 物理步长、4 ms 控制周期和 ±10 N 推力限幅。

## 实验与验收

| 实验 | 对两种控制器执行的相同操作 | 主要验收结果 |
|---|---|---|
| 初始偏角恢复 | 小车静止，摆杆从偏离直立 5° 处释放 | 能否扶正、恢复用时、小车移动距离 |
| 位置阶跃 | 直立稳定后，把位置目标从 0 改为 0.2 m | 位置与目标曲线、超调量、调节时间、稳态误差 |
| 脉冲扰动 | 向车体质心额外施加 2 N 水平外力，持续 0.1 s | 外力记录、最大偏角、恢复时间 |
| 参数摄动 | 分别将小车质量、杆质量、杆长改为标称值的 80% 和 120% | 六组实际物理模型的响应；杆的惯量随质量或长度同步更新 |
| 鲁棒性加分 | 固定标称控制器，将杆长从标称值的 50% 到 150% 按 10% 步进扫描，重复同一脉冲实验 | 画出峰值偏角和恢复时间随杆长的变化，标明成功与失败的实测区间 |

正式实验前固定运行时长、误差带、轨道边界和失稳判据。每次运行保存配置及原始 CSV，记录时间、目标、四个状态、控制力和外力。曲线与指标从 CSV 自动生成，失败工况也保留。两种算法的选择理由依据实际测得的跟踪、抗扰和控制力度写入报告。
