# 物理模型开环检查

验证范围为 Webots R2025a 中沿 X 的滑轨、小车和绕 Y 自由转动的摆杆。原始采样位于 `evidence/model-check`，各 31 行数据，持续 0.120 s。先启用传感器并推进 2 ms，取得第一笔有效读数时将实验时钟记为零，首笔速度估计为零。

| 输入 | Webots 在 0.120 s 的结果 | 与标称小角度模型的全程最大差值 |
| --- | --- | --- |
| 直立释放，+1 N 推车 | x=+0.006984 m，θ=−0.017920 rad | 位置 0.00011435 m，角度 0.00029948 rad |
| 初始 +5°，控制力为零 | θ 由 0.087276 rad 增至 0.106291 rad | 位置 0.00003945 m，角度 0.00088102 rad |

分析模型中心差分与解析雅可比最大差为 8.67×10⁻¹²。复核命令为 `python tools/run.py --open`、`python tools/model.py` 和 `python tools/check_plant.py`。这组结果用于核对标称小角度、短时开环响应。
