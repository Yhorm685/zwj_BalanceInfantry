# PID 闭环验证

使用串级 PID 从冷启动运行 5° 初始偏角、0.2 m 阶跃和 2 N × 0.1 s 脉冲三个标称工况。三份 CSV 各含 3501 个样本，覆盖 0 至 14 s。按实验协议的联合位置与角度误差带，恢复或调节时间依次为 1.520 s、1.588 s 和 1.084 s。对脉冲积分得 0.200 N·s。

C++ 测试覆盖倾角指令限幅、推力限幅、正常积分与复位。用 Webots 自带的 g++ 编译 `tests/check_pid.cpp` 并运行，四项均通过。模型、整定过程以及原始采样分别见同版本的 `docs/model.md`、`docs/pid.md` 及 `evidence/raw/pid-*.csv`。
