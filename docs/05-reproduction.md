# 实验交付复核

Webots R2025a，Windows x64；实验口径见 [协议](../experiments/protocol.md)。运行全部 34 个独立工况，每次 3501 个时刻，采样间隔 0.004 s，即每次覆盖 14.000 s。34 次均满足终点前至少持续 0.5 s 的联合误差带要求。利用另一套基于 CSV 的逐行计算独立复核了全部运行的判定、调节时间、峰值摆角、均方根推力和外力冲量。

Webots 有画面渲染模式录制 [PID](../evidence/video/demo-pid.mp4) 和 [LQR](../evidence/video/demo-lqr.mp4)。两段视频各含 348 帧、H.264、960×540、25 fps，播放时长 13.92 s，对应的演示 CSV 均覆盖 14.000 s。两段视频均已由 FFmpeg 从头到尾解码。画面左上显示算法、事件、时间、目标、小车位置和角度。

在工作目录重新构建最终控制器，并直接启动未改动的默认 `worlds/balance.wbt`，第 14 秒时目标为 0.2 m，位置为 0.1999986045 m，角度为 −4.1423×10⁻⁷ rad。启动器在本机于 Webots 退出后转出控制台文本；自动验收设置进程内环境变量使控制器在这一时刻主动正常退出。交互式演示继续维持平衡。
